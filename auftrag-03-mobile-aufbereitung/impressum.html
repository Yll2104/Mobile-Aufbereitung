Datenschutz

Der Schutz deiner persönlichen Daten ist uns wichtig. Personenbezogene Daten werden nur verarbeitet, soweit dies für die Bearbeitung deiner Anfrage und die Terminvereinbarung erforderlich ist.

Wenn du unser Buchungsformular verwendest, werden die von dir eingegebenen Daten zur Bearbeitung deiner Terminanfrage verarbeitet.

Welche Daten werden verarbeitet?

Je nach Eingabe können insbesondere Name, E-Mail-Adresse, Telefonnummer, gewünschtes Paket, Wunschdatum, Wunschzeit, Standort, Fahrzeug und deine Nachricht verarbeitet werden.

Google Sheets / Google Apps Script

Zur Verwaltung von Terminanfragen kann ein Google-Dienst beziehungsweise Google Apps Script eingesetzt werden. Die über das Formular übermittelten Daten können dabei in einer von uns verwalteten Google-Tabelle gespeichert werden.

Die Verarbeitung erfolgt ausschließlich zur Bearbeitung und Organisation von Terminanfragen.

Kontakt
